Вход в админку

Админка сохраняет изменения прямо в твой репозиторий на GitHub. Для этого нужен ключ доступа (токен). Его делают один раз.

  1. Открой создание токена на GitHub ↗.
  2. Token name: любое, например «Админка сайта». Expiration: 1 год.
  3. Repository access: Only select repositories, выбери timofeygorev.
  4. Permissions: найди Contents и поставь Read and write.
  5. Нажми Generate token, скопируй токен и вставь ниже.

Токен хранится только в этом браузере. Никому его не показывай. Если потеряешь, просто создай новый.

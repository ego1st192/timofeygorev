# Сайт Тимофея Горева

Личный сайт-портфолио. Тексты, фото и ссылки лежат отдельно от оформления, поэтому их можно менять через админку, не трогая код.

## Что где лежит

- `index.html` - оформление сайта. Трогать не нужно.
- `data/` - все тексты и ссылки:
  - `profile.json` - главная, бейдж, соцсети, почта, резюме
  - `work.json` - раздел «Работа»: опыт, образование, навыки
  - `print.json` - «3D-мастерская»: фото и список работ
  - `about.json` - «Обо мне»: награды, проекты, спорт
  - `news.json` - новости обо мне
- `media/` - фотографии и резюме.
- `.pages.yml` - настройка админки.

## Как редактировать

1. Открыть https://app.pagescms.org и войти через GitHub.
2. Выбрать репозиторий сайта.
3. Слева выбрать раздел, поменять текст или загрузить фото, нажать «Save».
4. Через 1-2 минуты изменения появятся на сайте.
